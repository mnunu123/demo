## 한 줄 상태

데모 완성. 키 없이 배포해도 전체 흐름(제품 → 커뮤니티 → 수집 → 분석 → 초안 → 쇼츠)이 동작합니다. 테스트 67개 통과, `next build` 통과, 데스크톱·모바일·다크 모드 화면 확인.

## 실행

```bash
npm install
npm run dev        # http://localhost:3000
npm test           # vitest
npm run build      # 배포 전 확인
```

- 체험: `/studio?sample=1` (가상 제품 Shiplog, 샘플 데이터라 항상 같은 결과)
- 실제 URL: 첫 화면에 넣으면 `/studio?url=...&p=reddit&p=x&p=hn`

## 무엇이 진짜로 동작하고 무엇이 샘플인가

| 부분 | 키 없음 | 키 있음 |
|---|---|---|
| 제품 페이지 읽기 | 서버가 직접 가져와 규칙 기반 추출 (막히면 직접 설명 입력) | Claude가 추출 내용을 정리 |
| Hacker News | 실시간 (Algolia, 키 불필요). 실패 시 샘플 | 동일 |
| Reddit | 공개 .json 시도 → 클라우드 IP에서 대부분 막힘 → 샘플 | `REDDIT_CLIENT_ID/SECRET`로 OAuth 실시간 |
| X | 샘플 | `X_BEARER_TOKEN`으로 실시간 (호출마다 과금) |
| 붙여넣기 | 동작 (어떤 커뮤니티든) | 동일 |
| 현지 가이드 | 통계로 자동 작성 | Claude가 통계를 읽고 작성 |
| 초안 | 템플릿 | Claude (실패 시 템플릿 + 이유 표시) |
| AI 글 금지 커뮤니티 | 뼈대 | 뼈대 (키가 있어도 대신 쓰지 않음) |
| 쇼츠 | 템플릿 | Claude |

샘플 커뮤니티 6곳: r/SideProject, r/SaaS, r/webdev, r/startups, X #buildinpublic, Show HN. 글과 규칙은 데모용으로 직접 쓴 합성 데이터이고 화면에 "샘플(합성)"로 표시됩니다. Show HN 규칙은 실제 가이드라인을 짧게 옮긴 것입니다.

## 배포 직후 확인 (5분)

1. `/api/health` → `{"llm":"none","reddit":"public","x":false,"hn":true,...}` 같은 응답
2. `/studio?sample=1` → 결과 화면까지 나오는지
3. 실제 URL 하나로 분석 → Show HN 탭이 "실시간 수집"으로 뜨는지 (HN은 키 없이 됨)
4. `ANTHROPIC_API_KEY` 넣고 재배포 → 상단에 `LLM claude-sonnet-5-5`, 초안 위에 "LLM 초안"
5. Reddit 탭이 샘플로 뜨면 정상입니다 (OAuth 키가 없으면 클라우드 IP에서 막힘)

## 알려진 한계

- 사용량 제한은 서버 인스턴스 메모리 기준이라 여러 인스턴스에서는 느슨합니다
- 네이버 스마트스토어처럼 봇 차단이 강한 쇼핑몰은 서버에서 페이지를 못 읽습니다(실제로 429 응답 확인). 브라우저인 척 우회하지 않고, 이유를 보여 준 뒤 직접 설명 입력으로 넘어갑니다
- 자바스크립트로 그리는 페이지(SPA)는 받은 HTML에 내용이 거의 없어서, 감지되면 직접 설명 입력으로 넘어갑니다
- 제품 링크의 추적 꼬리표(utm, NaPm 등)는 자동으로 지웁니다
- 템플릿 초안은 제품 정보가 영어일 때 자연스럽습니다. 한국어 페이지는 "제품 정보 고치기"에서 영어 한 줄 소개와 기능을 넣어 주세요 (LLM이 있으면 자동 번역)
- 글 유형 분류와 현지 표현 사전은 영어 기준입니다
- 샘플 데이터 규모는 커뮤니티당 16~18개라 상위 25% 비교는 경향만 보여 줍니다
